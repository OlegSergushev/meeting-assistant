# Спецификация формата протокола (для парсера)

Формат рассчитан на детерминированный разбор конвертером в .docx.

## Грамматика

```
document   := h1 blank date_line participants_line blank section*
h1         := "# Протокол встречи: " text
date_line  := "**Дата:** " (date | PLACEHOLDER)
part_line  := "**Участники:** " (name (", " name)* | PLACEHOLDER)
section    := h2 blank body blank
h2         := "## Обсуждение" | "## Решения" | "## Задачи"
body       := bullet_list | task_table
bullet_list:= ("- " text "\n")+
task_table := header_row separator_row task_row+
header_row := "| Задача | Ответственный | Срок |"
separator  := "|---|---|---|"
task_row   := "| " text " | " (name | PLACEHOLDER) " | " (date | PLACEHOLDER) " |"
date       := YYYY-MM-DD
PLACEHOLDER:= "Не указано"
```

## Гарантии

1. Три секции H2 присутствуют всегда, в фиксированном порядке.
2. Внутри «Задачи» — всегда таблица, минимум одна строка данных.
3. Плейсхолдер — строго `Не указано`.
4. Даты — строго `YYYY-MM-DD`.
5. Никакого текста вне грамматики.

## Что делать парсеру при нарушении

- Отсутствует секция → подставить секцию с плейсхолдером.
- Битая строка таблицы (не 3 колонки) → заменить всю строку на
  `| Не указано | Не указано | Не указано |` и записать warning.
- Неизвестный H2 → игнорировать, warning.
