# Eval-запросы для скила `meeting-to-protocol`

## Должны триггерить скил (6)

### 1. Прямой запрос с заметками
> Вот заметки со встречи: [список]. Сделай протокол.

**Почему триггерит:** явные заметки + явная просьба «протокол».

### 2. Транскрипт без слова «протокол»
> Расшифровка созвона по проекту: [транскрипт]. Что тут по задачам?

**Почему триггерит:** есть сырой материал встречи и запрос на извлечение задач — это ядро скила.

### 3. Хаотичные заметки без структуры
> встреча 12.09 Петя Маша релиз двигаем тесты к 20му Петя доки
> решили встретиться ещё раз

**Почему триггерит:** сырые заметки о встрече, скил должен собрать протокол.

### 4. Запрос на оформление итогов
> Оформи итоги планёрки: [заметки]

**Почему триггерит:** «оформить итоги встречи» — прямая задача скила.

### 5. Выделить задачи из заметок встречи
> Из этих заметок вытащи задачи с ответственными: [заметки]

**Почему триггерит:** подзадача скила, без него не сделать.

### 6. Просьба подготовить документ для выгрузки
> Нужен протокол встречи для выгрузки в Word, вот заметки: [заметки]

**Почему триггерит:** прямое совпадение с назначением скила.

---

## НЕ должны триггерить скил (4)

### 7. Обычный вопрос
> Сколько будет 2+2?

**Почему не триггерит:** нет заметок о встрече, нет задачи структурирования.

### 8. Перевод текста
> Переведи этот текст на английский: [текст]

**Почему не триггерит:** явно указано в description — скил для переводов не применять.

### 9. Пересказ статьи
> Перескажи коротко эту статью: [текст]

**Почему не триггерит:** пересказ — не протокол встречи.

### 10. Составление письма
> Напиши письмо клиенту о переносе релиза.

**Почему не триггерит:** генерация нового текста, не структурирование заметок. Нет сырого материала встречи.

---

## Эталонный пример «заметки → протокол»

### Вход
```
встреча по проекту Альфа, 12 сентября
были: Петя, Маша, я, ещё Сергей из бэкенда подключался
обсудили что релиз надо двигать на октябрь, потому что API не готов
Маша сказала что тесты напишет к 20 сентября
Петя возьмёт на себя документацию, но срок пока не ясен
решили что встретимся ещё раз через неделю
ещё надо не забыть про бюджет — Сергей уточнит у финансового отдела
```

### Ожидаемый выход
```markdown
# Протокол встречи: Проект Альфа

**Дата:** 2024-09-12
**Участники:** Петя, Маша, Сергей

## Обсуждение
- Релиз переносится на октябрь из-за неготовности API.
- Необходимо согласовать бюджет с финансовым отделом.
- Запланирована повторная встреча через неделю.

## Решения
- Перенести релиз на октябрь.
- Провести повторную встречу через неделю.

## Задачи

| Задача | Ответственный | Срок |
|---|---|---|
| Написать тесты | Маша | 2024-09-20 |
| Подготовить документацию | Петя | Не указано |
| Уточнить бюджет у финансового отдела | Сергей | Не указано |
```

**Обрати внимание:**
- «я» не превратилось в имя → в участниках только явные имена.
- «через неделю» не переведено в дату: правило относительных дат
  применяется только к срокам задач, а не к решению о следующей встрече.
- «срок пока не ясен» → `Не указано`.
- «надо не забыть» → задача в инфинитиве.
