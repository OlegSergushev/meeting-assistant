# Маршрут: недостающие данные

Применяется, когда в заметках нет ответственного, срока, даты
или участников. Правило одно: **не выдумывать, ставить `Не указано`**.

## Таблица решений

| Что отсутствует | Что делать |
|---|---|
| Тема встречи | `# Протокол встречи: Не указано` |
| Дата встречи | `**Дата:** Не указано` |
| Участники | `**Участники:** Не указано` |
| Пункты обсуждения | `## Обсуждение` + `- Не указано` |
| Решения | `## Решения` + `- Не указано` |
| Задачи | таблица с одной строкой `| Не указано | Не указано | Не указано |` |
| Ответственный у задачи | ячейка `Не указано` |
| Срок у задачи | ячейка `Не указано` |

## Примеры

### Вход
```
созвон, обсуждали релиз, надо дописать документацию
```

### Выход
```markdown
# Протокол встречи: Не указано

**Дата:** Не указано
**Участники:** Не указано

## Обсуждение
- Обсуждали релиз.

## Решения
- Не указано

## Задачи

| Задача | Ответственный | Срок |
|---|---|---|
| Дописать документацию | Не указано | Не указано |
```

## Запрещено

- Писать «не назначен», «нет», «—», «TBD», «уточняется».
- Оставлять ячейку пустой.
- Задавать пользователю уточняющие вопросы.
